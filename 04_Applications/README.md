# Applications / 応用

This directory contains public-facing conceptual applications of Scientific Ontology.

It is not a private implementation layer.  
It does not contain runtime specifications, persona core parameters, intervention variables, or private evaluation logs.

このディレクトリは、存在境界論｜Scientific Ontology の概念を、AI、人格、社会、創作、実践などの具体領域へ接続する公開応用層である。

非公開実装層ではない。  
ランタイム仕様、人格コアパラメータ、介入変数、非公開評価ログは含めない。
