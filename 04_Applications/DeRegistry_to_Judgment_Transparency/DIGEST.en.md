## What this volume records

This volume documents a short but dense sequence of experiments conducted on August 21–22, 2026. The work began as a De-Registry test on an old Optional Axiom atlas and developed into a method for making judgment generation inspectable.

The key shift was from asking whether a model produced the "right" S/E/U/P labels to asking where a judgment contacted its source, whose commitment it represented, which phase transitions it crossed, which transformations were omitted, where objections could return, and what remained unresolved.

## Chronicle snapshots

1. **De-Registry.** Proper names, schools, and domain labels were tested as provenance / return keys rather than direct scoring keys.
2. **Protocol underdetermination.** Large Sol–Luna differences exposed undocumented decision state rather than cleanly isolating model capability.
3. **The S5 festival.** A Luna run produced S5 for 16 of 17 cases while consistently exposing its triggers and score-changing conditions. This made the upstream attribution error inspectable instead of hiding it through post-hoc normalization.
4. **Topology first.** The primary audit moved to five communication positions: Anchor Integrity, Phase Integrity, Path Legibility, Return Reachability, and Open-End Retention. Deviations were recorded only as Cut, False Link, Both, or Unresolved before optional naming.
5. **Three-layer transformation audit.** Four cases were separated into domain-authoritative description, Optional Axiom description, and SO-derived interpretation. The audit localized transformations such as vocabulary flattening, warrant-mode changes, and suspected authority bypasses.
6. **Judgment transparency.** The current application goal is not to guarantee truth but to expose how a judgment was generated so that disagreement can be localized, contested, and revised.

## Current method core

Primary topology:

- Anchor Integrity
- Phase Integrity
- Path Legibility
- Return Reachability
- Open-End Retention

Primitive deviation labels:

- Cut
- False Link
- Both
- Unresolved

Raw anomalies are preserved before naming. Higher-order labels such as E/U/S/V/P, when used, should not retroactively rewrite lower-level observations.

## Strong non-claims

This volume does not establish that these five positions are necessary and sufficient conditions for truth or objectivity. It does not establish a general superiority of Sol, Luna, or another model. It does not claim that ultimate grounds do not exist. It does not give SO authority to define external philosophical, scientific, political, or strategic domains.

The more modest claim supported by the experiments is that externalizing judgment paths can sometimes turn model disagreement into inspectable differences in attribution, phase transition, warrant path, return path, and residual handling.

## Why this is an application

The method is reusable as a public interface for reviewing judgments, cross-domain interpretations, AI assessments, commensuration, and repository governance. It is therefore placed in `04_Applications`, while the original De-Registry workbench remains in `05_Research_Notes` as provenance.
