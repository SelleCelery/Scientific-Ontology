## 0. この巻の役割

この巻は、旧Optional Axiom corpusを用いたDe-Registry実験から、判断生成を通信トポロジーとして外在化する方法へ至るまでの発展を、**紀**と**伝**に分けて記録する。

- **紀**は、その時点で凍結できた成果のスナップショットである。
- **伝**は、その成果へ至るために何を試し、どこで破れ、何が次の試行を必要にしたかを記録する。

現在の理論から過去を一本化しない。失敗した再較正、モデル差、奇妙な結果、SO自身に不利な監査結果を含め、その時点で観測された形のまま履歴へ残す。

この巻が扱う中心問題は「何が真か」を直接決めることではなく、**ある判断が何に接触し、誰の命題を扱い、どの位相を通り、どの経路で結論に達し、異議がどこへ戻れ、何が未閉鎖として残ったかを可視化すること**である。

## 2. 現時点の方法核

判断透明性の一次観測は、次の五つの通信位相で行う。

- **接点整合性 / Anchor Integrity**
- **位相整合性 / Phase Integrity**
- **経路可読性 / Path Legibility**
- **返路実効性 / Return Reachability**
- **開放端保持 / Open-End Retention**

逸脱は詳細分類へ先に押し込まず、まず次の原始分類だけを使う。

- `Cut`
- `False Link`
- `Both`
- `Unresolved`

生ログは、命名より先に保存する。

```text
Observed anomaly:
Affected nodes:
Expected path:
Observed path:
Possible cut:
Possible false connection:
Named pattern: optional
Unresolved difference:
Return point:
```

S/E/U/V/P等のラベルは、この一次観測を上書きする本体ではなく、必要な場合に後段から投影される補助ラベルとして扱う。

## 3. 非主張境界

この巻は次を主張しない。

- ここに記録されたAI出力が正解である。
- Sol、Luna、その他のモデルの一般的能力優劣が確定した。
- 五軸が真理の必要十分条件である。
- `Cut / False Link / Both / Unresolved` が逸脱を網羅する最終分類である。
- 「根源的根拠は存在しない」という形而上学的結論が得られた。
- 外部哲学・物理学・政治思想・戦略理論をSOが定義または裁定する権限を得た。

現在支持されているのは、より弱い運用命題である。判断経路を外在化すると、モデル間・時点間の不一致を、単なる結論差ではなく、接点・帰属・位相・経路・返路・残差の差として局在化できる場合がある。
