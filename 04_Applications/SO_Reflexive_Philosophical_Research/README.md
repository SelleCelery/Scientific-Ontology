## 0. この研究プログラムの役割

このディレクトリは、存在境界論（Scientific Ontology / SO）を用いて外部対象を説明するためだけの場所ではない。

哲学的命題や異なる記述体系をLLMへ通したとき、何が保持され、何が変形され、どこで責務・権威・根拠・残差が移動するかを観察し、その結果をSO自身の監査へ返すための長期研究プログラムである。

研究の発端は、旧Optional Axiom corpusをstress-test corpusとして用いたDe-Registry実験だった。そこで得られた成果は当初の試験目的を越え、AIの判断生成、帰属、通約、変換経路、異議の返路、未閉鎖点を可視化する「判断透明性」の研究へ発展した。

第一巻はその発展史を保存する。研究プログラム全体は第一巻より広く、今後の問い、SO正本群への自己監査、非公開形而上学原液からの公開再構成、成立史の再読を含む。

## 2. 研究運動

この研究は、完成した研究分野を先に分類して進めない。

```text
① 哲学的研究
      ↕
② SO正本群への即時自己監査
      ↕
③ 前提となる根拠の明示と公開再構成

①〜③の実際の往復履歴 → ④ SO成立史の再読・紀伝体化
④で反復して現れた構造 → ⑤ 個別研究分野候補
⑤は再び①へ返して検査
```

①は長期の問いを置く研究場である。②では①で得た方法をSO自身へ返し、正本を書き直す前に、現在の主張責務、接続、帰属、変換、残差を露出させる。③では、②で露出した前提や根拠を明示し、その価値を異なる記述体系との通信可能性、異議可能性、修正可能性から検討する。

この往復自体が④の履歴になる。⑤は先に作らず、④を書いているときに反復して現れた問題を後から拾う。

## 3. Public / Private Boundary

この研究は、非公開の応用形而上学資料、AMP系資料、ITS、PINGER等へ接触する可能性がある。

それらは公開SOの秘密の正本でも、隠れた最終根拠でもない。公開へ出す場合は、私的原液をそのまま権威として提示せず、問い・構造・系譜を抽出し、公開側で責務、適用範囲、標準領域との非同一性、異議、残差、返路を明示して再構成する。

したがって、この公開研究プログラムだけから非公開原液を再構成できることを目標にしない。

## 4. Volumes / 紀伝体

`volumes/` は、その時点で成立した成果と、それへ至る試行・失敗・転回を歴史的断面として保存する。

- **紀** — ある時点で凍結した成果・状態。
- **伝** — 試行、失敗、異議、修正理由、未解決差分。

Volumeは現在の理論から過去を整形し直すための場所ではない。後続研究で見解が変わっても、当時の記録は当時の記録として保持する。

## 5. Navigator上の役割

Navigatorでは、このREADMEを研究プログラムの第一入口とする想定である。

個別のraw evidenceを大量に検索入口へ登録するのではなく、研究文脈、問い台帳、各Volumeの入口、現在の方法文書を主要なnavigation identityとして扱う。

証拠群はVolumeから必要に応じて辿る。

## 6. 非主張境界

この研究プログラムは次を主張しない。

- LLMが哲学的真理を自動的に決定できる。
- 判断透明性が真理や妥当性を保証する。
- SOが外部専門領域の定義権限を取得する。
- 非公開形而上学原液が標準科学として成立している。
- ①〜⑤が完成した研究分類である。
- Volumeの長い履歴それ自体が理論の真理を証明する。

ここで重視するのは、判断・変換・異議・改訂がどこを通ったかを後から検査可能にすることである。
