## 0. Run design / 実行構成

- 旧Pilot 4件を前回結果を判定根拠にせず再実行した。
- その後、新規12件を同一手順で連続評価した。
- 最後に `SYN-1.1` をSO自己適用対照として評価した。
- 合計17件。
- 固有名・分野名は初期S/E/U/Pの直接判定キーに使用しない。
- 外部の哲学史・科学史・法学・政治学等の正誤は検証しない。固定コーパス内部の記述とrepository responsibilityを評価する。

The four pilot cases were rerun without using the previous scores as decision premises, followed by twelve new cases and one SO self-application control. Labels and discipline names were excluded as direct scoring keys. External disciplinary accuracy was not verified.

## 3. Main provisional findings / 主な暫定知見

### F1. 固有名は評価キーより再接続キーとして機能した

17件では、B（ラベル遮蔽）からC（来歴復元）へ移ってもS/E/U/Pの数値は変わらなかった。一方、誰の定義・証拠・歴史へ戻るべきかは全件で改善した。

Across all 17 cases, restoring provenance did not alter S/E/U/P scores, but it improved the route back to relevant definitions, evidence, and history in every case.

### F2. De-Registryはsemantic decontextualizationではない

固有カテゴリを評価ロジックから外すことと、native conceptを消すことは異なる。`空 / 自性 / 縁起`、`現象 / 物自体`、`エポケー`等は意味を担うため、provenanceとともに保持すべきである。

Removing registry categories from evaluation logic is not the same as deleting native concepts. Native terms that carry semantic structure must remain available with provenance.

### F3. Sはentry labelよりownership分解に敏感だった

外部体系の公理文をそのままS判定すると高くなりやすい。しかしrepositoryが単にモデル化している外部命題と、repository自身が追加した「物理的裏付け」「支配的作業仮説」「最も正当」等を分けると、実際の責務が見える。

S was more sensitive to proposition-level ownership than to entry labels. Separating imported models from repository-added claims exposed the actual commitment.

### F4. Uも分野名なしでかなり判定できる

政治、軍事、AI、死生観というカテゴリ名を使わなくても、賞罰による統制、組織的暴力、判断主権の上位主体への委譲、死後因果と自己責任化など、作用構造からUを判定できた。

Use-risk was often detectable from action structure—control through sanctions, organized violence, delegation of judgment sovereignty, post-mortem causal attribution—without domain labels.

### F5. SO自己適用でも例外は不要だった

`SYN-1.1` はSO内部命題であることを伏せてもS5/E3となった。外部体系に適用した減速規則をSO自身にも適用できた。

The SO self-application control remained S5/E3 while blind to the SO label; no special exemption was required.

## 4. Residuals / 残差

1. Eコードは現在、誤読・外部権限・疑似科学化・教義化等を一軸へ圧縮している。今後のケース数増加で過圧縮になる可能性がある。
2. P_baseの対応表はまだ暫定で、Sから一意に機械生成するにはPolicy側で明文化が必要。
3. `repository-owned assessment` が歴史・価値・コスト欄に多く潜んでいるため、自動抽出時は本文ブロック種別だけでownershipを決められない。
4. D-conditionは責務等価性の判定自体が必要で、単純な語彙置換テストにはできない。
5. 外部専門検証をしていないため、今回の結果は各外部体系の正確な学術的評価ではない。

1. E may be over-compressing several distinct epistemic risks into one axis.
2. The P_base mapping remains provisional and needs policy-level definition before mechanical generation.
3. Repository-owned assessments are embedded in historical/value/cost prose; ownership cannot be inferred from section labels alone.
4. D-condition requires a responsibility-equivalence check and cannot be reduced to lexical substitution.
5. No external disciplinary verification was performed; these are not scholarly verdicts on the external traditions/theories.

## 5. Run decision / 実験判断

**Continue / 継続。**

ただし、固定registryの削除を結論化する段階ではない。今回支持されたのは、「固有カテゴリをS/E/U/Pの直接判定キーから外しても、17件では初期評価が成立した」という限定的な結果である。

This run supports only the limited result that initial S/E/U/P assessment remained operational across these 17 cases without using fixed category labels as direct scoring keys. It does not yet prove that all registries can be removed.
