## 第一紀　De-Registry

旧Optional Axiom atlasを、高密度なテストコーパスとして扱った。目的は思想名や専門分野名を削除することではなく、それらを評価権限から外し、命題・責務・範囲・外部権限依存から判定できるかを試すことだった。

初期17ケースでは、固有名やprovenanceを復元したことだけを理由とするS/E/U/Pの変更は0/17だった。Luna全83ケースでも同型の結果が得られた。これにより、少なくともこの固定コーパスでは、固有名をscoring keyではなくprovenance / return keyとして扱える可能性が支持された。

この時点では、S/E/U/Pそのものの妥当性は確定していない。得られたのは「何という名前か」と「何を引き受けているか」を分けられる可能性である。

## 第二紀　モデル差からProtocol差へ

SolとLunaで17ケースのS/E/U/Pを比較すると大きな差が出た。当初はモデル固有差の可能性が考えられたが、再較正実験によって別の問題が露出した。

Solの17ケース評価には、ファイルに書かれていない会話履歴由来の判定基準が働いていた可能性が高い。Lunaにはその履歴がなかった。再較正ルールを増やすと一致率の一部は改善したが、判断空間そのものが圧縮される現象が起きた。

ここで次の暫定知見が得られた。

> 客観化を、分類規則の追加と同一視しない。

必要なのは結果を一意化する規則数ではなく、判断がどの操作を通って生成されたかを他の主体が検査できることではないか、という研究線が開いた。

## 第三紀　帰属の発見

Solの暗黙Metadata Assessmentを再構成し、Lunaへ与えた十分性候補実験では、17件中16件がS5になった。

結果は極端だったが、Lunaはそれを分布に合わせて修正しなかった。同じ発火原理を横断適用し、各ケースにscore-changing conditionを残した。

このrunによって、問題をS5という結論そのものではなく、その上流へ局在化できた。Optional Axiomの文章をrepositoryが書いたことと、その命題内容をrepository自身が真としてendorseしたことが直結されていた。

ここから、少なくとも次を分ける必要が明確になった。

- text author
- represented voice/system
- repository endorsement
- repository-derived addition
- commitment owner used for downstream judgment

透明な誤りは、隠れた一致より監査可能である。このrunは、そのことを示す実験例になった。

## 第四紀　通信トポロジー

妥当性条件をチェックリストとして増殖させる代わりに、判断が通過する通信位相へ再配置した。

本体は次の五軸とした。

1. 接点整合性 / Anchor Integrity
2. 位相整合性 / Phase Integrity
3. 経路可読性 / Path Legibility
4. 返路実効性 / Return Reachability
5. 開放端保持 / Open-End Retention

逸脱は、細かな名称を先に要求せず、`Cut / False Link / Both / Unresolved`へだけ投影する。生ログを先に凍結し、下流ラベルから上流観測を修正することを禁止した。

Topology-firstの17ケースrunでは、SYN-1.1応用形而上学に特例を設けず、5軸すべてがfailedとなった。物理語彙から形而上学的実在への移行、統合能力からメタ権威への移行、反論を高次統合へ回収する返路の欠如が同一手順で検出された。

SOが監査主体であると同時に監査対象でもある、という運用上の対称性が成立した。

## 第五紀　三層変換監査

次に、外部体系そのものと、SOによって既に加工された表象を分ける必要が生じた。

4ケースについて、次の三層を固定した。

```text
domain-authoritative description
  -> Optional Axiom description
  -> SO-derived interpretation
```

G-3では、`svabhāva`等をめぐる論証・解釈差が、包括的な関係主義的存在論へ圧縮される箇所が観測された。

S-8では、`fa`の多義性が「法」へ固定され、歴史的思想がシステム工学・現代的公平性へ接続される変換が観測された。

E-9では、数学的形式・測定・解釈・存在論を外部sourceが区別しているのに対し、Optional Axiomでは観測・収縮・共同創造が連続化され、SO内部の定義・定理へ接続されていた。

ST-2では、政治目的と軍事手段の相互関係が、政治的意図を上位原理とするシステム的読解へ変換される箇所が観測された。

ここで重要なのは、外部体系そのものの誤りとして処理しなかったことである。逸脱はA→B、B→C、またはA→C bypassという変換エッジへ局在化された。

## 第六紀　判断透明性

現時点の最も安定した成果は、真理の定義ではなく、判断生成を透明化する方法である。

判断について、少なくとも次を再構成可能にする。

- 何に接触したか
- 誰の命題として扱ったか
- どの位相に置いたか
- 何を変換・捨象したか
- どの経路で結論へ進んだか
- 異議はどこへ返せるか
- 何を未閉鎖として残したか

異議が出た場合、根拠を追加する、接続を修正する、主張を撤回する、対抗主張の責務を新たに立てる、または未解決として停止する。

根拠系列が停止したとき、その停止を根源的真理と偽装しない。現時点では「究極根拠は存在しない」とは主張しない。観測対象は、根拠の根拠がどこで、どのように止まり、その停止がどの位相に属するかである。

## 現紀末尾の仮接続

根拠とは、無限に遡った先の唯一の根を所有することではなく、ある判断がどこで大地に接しているかを示すことなのかもしれない。

ただし、大地の評価と、その大地に生える植物の適性は別である。ある土壌でよく育ったことは、その土壌だけが世界であることを意味しない。

この比喩は形而上学的結論ではない。現段階では、判断が接触する地盤と、そこから先の仮接続を区別するための研究上の比喩として保持する。
