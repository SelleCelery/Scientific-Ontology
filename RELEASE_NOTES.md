## Release Notes: Scientific Ontology Public Edition v2.1.0

Release date: 2026-06-10

## Purpose

This release provides a public-facing conceptual archive of Scientific Ontology.

It organizes the project into overview materials, Sat / Truth foundations, Raj / Beauty constructive frameworks, Tam / Goodness public safety-interface materials, and bounded Research Notes.

This release is intended as a public reference, not as a complete formal specification, empirical scientific theory, or implementation package.

## Major changes from v2.0

- Added `00_Overview/` as a navigation and governance layer.
- Added `Scientific_Ontology_System_Map.md`.
- Added `Scientific_Terminology_Protocol.md`.
- Added publication-risk classification using E-code and U-code.
- Revised the claim-strength table for History-Field Topology.
- Reorganized Research Notes as a bounded space for high-claim-strength conceptual applications and structural readings.
- Added clearer separation between public conceptual materials and non-public implementation-facing materials.
- Updated repository-level README, roadmap, and glossary materials.

## Included in this release

- Public overview documents
- Public Sat / Truth foundation documents
- Public Raj / Beauty framework documents
- Public Tam / Goodness safety-interface documents
- Research Notes with explicit claim boundaries
- Glossary and roadmap materials

## Not included

This release does not include:

- private core materials
- unpublished axiomatic drafts
- non-public runtime materials
- detailed implementation schemas
- detailed operational parameters
- internal evaluation taxonomies
