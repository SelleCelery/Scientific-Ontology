## Purpose

Scientific Ontology (SO) / 存在境界論 Public Edition v4.0.0 is a public documentation release that reorganizes the repository as an English-accessible public entrance while preserving Japanese as the primary conceptual reference where meanings diverge.

This release consolidates the public Japanese name **存在境界論** while retaining **Scientific Ontology** as the English project name. It also clarifies the relation between existing sciences and Scientific Ontology / AMP / ITS as a difference in explanatory ground: high-entropy observation-based science and low-entropy activity-based top-down theory may intersect on shared vocabulary, but they do not originate from the same explanatory home base.

This release remains a public conceptual archive and navigational interface. It is not a complete formal specification, empirical scientific theory, AI runtime package, policy doctrine, or disclosure of private core materials.

Scientific Ontology (SO) / 存在境界論 Public Edition v4.0.0 は、英語から入る読者を想定した公開入口としてリポジトリを再編しつつ、意味が分岐する場合には日本語を主要な概念参照として扱う公開文書版です。

本リリースでは、公開上の日本語名を **存在境界論** として整理し、英語名 **Scientific Ontology** を維持します。また、既存科学と Scientific Ontology / AMP / ITS の関係を、説明の本拠地の差として整理します。高エントロピーな観測ベースの科学と、低エントロピーな活動ベースのトップダウン理論は共有語彙上で接触しうるが、同じ本拠地から出発するものではありません。

本リリースは、公開用概念アーカイブおよびナビゲーション・インターフェースです。完全な形式仕様、経験科学理論、AIランタイムパッケージ、政策教義、非公開中核資料の開示ではありません。

### Changed

- Consolidated the public Japanese name as **存在境界論**, while retaining **Scientific Ontology** as the English project name.
- Redesigned the root README as an English-accessible public entrance, while leaving detailed theory descriptions to the relevant layer README files and documents.
- Standardized the README structure for first-level directories.
- Standardized the README structure for Research Notes subdirectories.
- Converted table-heavy Research Notes index material into an Obsidian-friendly bullet-list structure.
- Reorganized the Applications layer so that public AI boundary, AI usefulness, and AI personality documents are placed under `04_Applications/`.
- Moved `Meaning_As_Return_Orbit.md` out of the former `04_Applications/Personality_AI/` location and into the Tam / Goodness layer.
- Moved the science-position document from `00_Overview/` to `02_Raj_Beauty/`, where science-facing boundary dynamics and explanatory-ground questions are handled.
- Renamed or split selected Research Notes to avoid embedded version numbers in filenames and to separate Japanese authoritative text from English commensurated renderings.
- Updated local links and repository navigation after the structural changes.

### Clarified

- Clarified that Scientific Ontology is not a bottom-up empirical replacement for modern science.
- Clarified the distinction between high-entropy observation-based science and low-entropy activity-based top-down theory.
- Clarified that Japanese descriptions remain the primary conceptual reference where meanings diverge.
- Clarified that English text is a commensurated rendering, not a fixed word-for-word translation.
- Clarified that Research Notes may contain stronger hypotheses, analogies, physical-facing correspondence candidates, social-boundary analysis, and literary-ontological readings, but remain bounded and should not be treated as empirical proof, peer-reviewed physics, orthodox social science, or implementation specification.
- Clarified the public/private boundary: full AMP Core, full ITS theory, private runtime materials, persona core specifications, and detailed implementation-control materials remain outside the public repository.
- Clarified that failures, counterexamples, mismatches, residuals, and residues are resources for re-collation rather than material to be forcibly discarded.

### Withheld

- Full AMP Core remains outside the public repository.
- Full ITS theory remains outside the public repository.
- Private axiomatic drafts remain withheld.
- Non-public runtime materials, persona core parameters, implementation-control materials, operational thresholds, private evaluation maps, heat logs, and detailed simulation specifications remain withheld.
- Private source inventories and non-public governance maps remain withheld.
