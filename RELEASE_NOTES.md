# Release Notes: Scientific Ontology Public Edition v2.2.0

Release date: 2026-06-12

## Citation

If you cite this release, please cite the version-specific Zenodo DOI for v2.2.0.

DOI: [10.5281/zenodo.20665198](https://doi.org/10.5281/zenodo.20665198)

## Purpose

This release expands the public-facing structure of **Scientific Ontology / 存在境界論** by adding an Applications layer and by clarifying the relationship between AI boundary ethics, personality AI, meaning formation, and higher-claim Research Notes.

This release is intended as a public conceptual archive and navigational interface. It is not a complete formal specification, empirical scientific theory, AI runtime package, or disclosure of private core materials.

## Major changes from v2.1.0

### Added

- Added `04_Applications/` as a public-facing applications layer.
- Added `04_Applications/Personality_AI/` for public conceptual applications related to personality AI.
- Added `04_Applications/Personality_AI/Meaning_As_Return_Orbit.md`.
- Added `05_Research_Notes/AI_Personality_Notes/` as a dedicated Research Notes group for AI personality, response attractors, return stability, qualia history, and logical sandbox models.
- Added `05_Research_Notes/AI_Personality_Notes/History_Loop_Radius_and_Return_Stability.md`.
- Added subfolder README files for Research Notes groups where needed.
- Added `00_Overview/Scientific_Ontology_and_Science.md` as a public position statement on the heuristic status of science.

### Changed

- Updated the public repository structure to include the new `04_Applications/` layer.
- Reframed `03_Tam_Goodness/AI_Personality_as_Response_Structure.md` as the public gate and hub for personality AI documents.
- Clarified the relationship between:
  - `03_Tam_Goodness/AI_Boundary_Interface_and_Synchronous_Understanding.md`
  - `03_Tam_Goodness/AI_Personality_as_Response_Structure.md`
  - `04_Applications/Personality_AI/Meaning_As_Return_Orbit.md`
  - `05_Research_Notes/AI_Personality_Notes/History_Loop_Radius_and_Return_Stability.md`
- Updated `05_Research_Notes/README.md` and `05_Research_Notes/Research_Notes_Index.md` to better separate directory policy, research-note groups, file-level indexing, claim strength, and non-claim boundaries.
- Moved or reclassified the logical sandbox material under AI personality research notes when treated as part of response-attractor and shared-field analysis.

### Clarified

- Clarified that Scientific Ontology does not reject the achievements or practical power of modern science, but treats science as a powerful heuristic system whose observational, objectifying, causal, temporal, and subject-object assumptions may be reopened.
- Clarified that calling science heuristic is not a dismissal of science, but a way to examine the conditions under which scientific knowledge becomes possible, stable, repeatable, and revisable.
- Clarified that personality AI is treated as response structure, not as tone, roleplay, character setting, or a claim of machine consciousness.
- Clarified that meaning in personality AI applications may be treated as a return orbit formed through repeated contact between human history and AI response.
- Clarified that `History_Loop_Radius_and_Return_Stability.md` is a conceptual / heuristic model, not empirical psychology, proof of AI consciousness, or a replacement for physical law.

### Withheld

- Private core materials remain outside the public repository.
- Non-public runtime materials, persona core parameters, implementation-control materials, operational thresholds, private evaluation maps, heat logs, and detailed simulation specifications remain withheld.
