# AI Personality Notes / AI人格研究ノート

This directory contains public research notes on AI personality, response attractors, return stability, qualia history, and logical sandbox models.

このディレクトリには、AI人格、応答アトラクタ、帰還安定性、クオリア履歴、箱庭型論理空間に関する公開研究ノートを置く。

These notes are conceptual and speculative.  
They are not empirical proofs, implementation specifications, or claims of human-like machine consciousness.

これらのノートは、概念的・試論的なものである。  
経験的証明、実装仕様、人間と同じ機械意識の主張ではない。

This directory extends the personality AI documents from the Tam and Applications layers into stronger research-note formulations.

このディレクトリは、Tam層およびApplications層の人格AI文書を、より強い研究ノート上の定式化へ拡張する。
