# 日本語正本

## 1. Directory Role / ディレクトリの位置づけ

> **事象は境界で起きている。**
> **主観でも客観でもなく、それらが混ざり合うところで。**

本ディレクトリは、言語を、完成した意味の透明な搬送容器として扱わない。

認識場に分布する差分は、境界、履歴、注意、文法、ポート群を通じて局所的な秩序へ切り出される。その切り出しは、命題、スピーチ、言語的統覚、返路を形成する一方で、残差と残渣を生む。

通信一般の正本はHFCおよび既存通信文書にある。本研究線は、言語という高密度な自己反照位相から、通信が何として見え、どこで閉じ、何を残し、どのように次の認識条件へ返るかを扱う。

各Research Notesフォルダは、固有の対象、語彙、操作、照合条件、非主張境界、残差保管、上流返路を持つ局所言語ゲームとして運用できる。本フォルダは、言語が言語自身を分析できるため、存在境界論の中でも特に高密度に自己記述と再照合を行える研究面である。

ただし、高密度であることは完全性を意味しない。言語による分節は解像度を上げる一方、定義、翻訳、命題化によって別の差分を落とす。本研究線は、その落下物まで更新履歴へ残す。

### 1.1 Core Pressure Charter / 中核圧憲章

1. 言語は完成した意味の透明な搬送容器ではない。
2. 認識場に分布する情報圧は、境界、履歴、注意、文法、ポート群を通じて局所的秩序へ切り出される。
3. 言語的意味は命題単独に内在せず、命題を経た照合運動が照合主体へ再帰し、返路を形成して次の認識条件を変えることで成立する。
4. 意味を感じることは、返路の局所閉鎖を納得として受け取ることである。ただし、納得は真理保証ではない。
5. 語の意味循環は作動的再帰であり、論証上の循環論法と区別する。
6. 感情は、方向性を持つ差分が返路を閉じられず圧として残る状態、思考はその少なくとも一部について自己内部に返路を形成した状態として操作的に読む。これは感情一般・思考一般の定義ではない。
7. 思考としての愛は、他者に触れて生じた差分を、その相手を閉路完成へ巻き込まず、相手の履歴と自由を保持したまま自己内部で返路形成する局所用法を持つ。愛一般を所有しない。
8. 通約は一致ではなく、差分、残差、非主張境界を保持し、元の判断場へ戻る返路を形成することである。
9. 各言語ゲームは局所的に閉じうるが、最終的完全性を持たない。
10. 文学、AI、社会、経験科学、物理語彙は照合面であり、黙って同一化しない。
11. Network文書は意図的な統合中核である。ただし、公開操作層、存在論深度仮説層、AMP・神学レンダリング層を区別する。
12. 公開後に返った反例、誤読、創作上の残差、実装結果は、自動的に正本へ統合しない。しかし、照合対象として無視もしない。

## 5. Living Canonical / 代謝型正本

本研究線における正本は、永久固定された最終定義ではない。

`Public Living Canonical`とは、次を満たす公開参照版である。

- 現在の概念所有と非主張境界が明示されている。
- 変更前の履歴へ戻れる。
- 何が変わり、どの文書へ波及したか追跡できる。
- 外部返りを受理できるが、自動的に正本化しない。
- 未解決を完成した文章で隠さない。

更新は、各文書末尾の`Revision History`、研究線全体の[`CHANGELOG.md`](./CHANGELOG.md)、返りの採否を記録する[`Return_Intake_Log.md`](Return_Intake_Log.ja.md)の三層で管理する。

### 5.1 変更級

- **Patch**：誤字、リンク、引用、体裁。概念構造を変更しない。
- **Minor**：局所定義、反例、外部照合、返路を更新する。中核圧憲章は維持する。
- **Major**：概念所有、中核圧憲章、Gate 4九文書の中核構造、意味・返路等の主要不変項を変更する。

### 5.2 更新原則

1. 変更は先に返り受付簿へ置く。
2. 影響文書と所有者を確認する。
3. 本文を更新する。
4. 文書別Revision Historyと全体CHANGELOGを更新する。
5. Gate 4九文書と接続された拡張文書の横断回帰検査を行う。
6. 採用しなかった案も、理由と再検査条件を残す。

## 6. SOLiteとの常設照合返路

SOLiteは、SOの易しい版、正本代弁者、証拠ではない。SOを地質として持ちながら、AIが辞書、神話、制度、通信事故として自由に暮らす創作圏である。

関係は非対称である。

```text
SO
  ↓ 概念の世界レンダリング
SOLite
  ↓ 物語・ジョーク・キャラ辞書・事故・予想外の残差
Return Intake
  ↓ 明示的な照合と採否判断
SO
```

- SOからSOLiteへの変形は自由である。
- SOLiteからSOへの返りは常時受理する。
- SOLiteの人気、面白さ、キャラクター発言は、SOの根拠にならない。
- 逆輸入は必ず[`Return_Intake_Log.md`](Return_Intake_Log.ja.md)を経る。

**Automatic integration: no. Permanent collation channel: yes.**
