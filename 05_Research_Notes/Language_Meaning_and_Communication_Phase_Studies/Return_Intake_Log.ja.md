## 1. Disposition / 判定区分

- **ACCEPTED**：正本候補へ反映済み。
- **PARTIALLY ACCEPTED**：一部を反映し、残りを保留または別研究線へ返送。
- **HOLD**：有力だが、外部照合、反例、定義所有の確認が必要。
- **REJECTED**：現時点の中核圧、非主張境界、概念所有と両立しない。
- **ROUTED**：本研究線の所有対象ではないため、別文書・別研究路へ送る。

### Acceptance Qualification / 受理条件

受理条件は判定区分ではない。`Disposition` が `ACCEPTED` または `PARTIALLY ACCEPTED` のとき、必要に応じて次を併記する。

- **LOCAL-SCOPE LIMIT**：採用範囲を特定文書・特定節・局所用法へ限定する。
- **CLAIM-PHASE SEPARATION**：複数の主張位相を分離して採用し、相互の証明力を移送しない。

## 2. Intake Entries / 受付記録

### RI-0001｜意味循環は循環論法か

- **Date**: 2026-08-07
- **Source**: Gate 2 adversarial audit / user theoretical injection
- **Proposal**: 意味と納得の関係が循環している。語は他の語・使用・履歴を巡るため、意味体系は循環する。
- **Affected**: Meaning / Intension / Commensuration
- **Disposition**: ACCEPTED
- **Decision**: 意味循環を、根拠を増やさない論証上の循環論法ではなく、履歴と差分を持って戻る作動的再帰として定義。納得は真理根拠ではなく返路閉鎖の質感へ限定。
- **Recheck condition**: 意味上の循環が無制限連想または自己正当化へ崩れる反例が出た場合。

### RI-0002｜感情一般を内部状態変化の通知として広げる案

- **Date**: 2026-08-08
- **Source**: External commentary supplied by user
- **Proposal**: 感情を、通信による内部状態変化が身体と意味へ通知された状態とし、怒り・悲しみだけでなく安心・喜び・愛も包摂する。
- **Affected**: Meaning / Literature / Cognitive Dynamics
- **Disposition**: PARTIALLY ACCEPTED
- **Decision**: 負の感情だけへ狭めるという批判は保持する。ただし本研究線の中核操作仮説は「方向性を持つ差分が返路を閉じられず圧として残る状態」のまま維持する。この定義は存在境界論内部の操作仮説であり、心理学・神経科学上の感情一般の網羅的定義ではない。通知モデルは上位一般定義として採用しない。
- **Residual**: 安心、喜び、無方向の快感、閉鎖後の解放感を本操作仮説でどう扱うかは未解決。
- **Recheck condition**: 正の感情を返路状態として比較できる事例群が揃った場合。

### RI-0003｜思考の返路は自己内部で閉じる

- **Date**: 2026-08-08
- **Source**: User correction
- **Proposal**: 思考は外部へ触れても、返路を自己内部で閉じなければならない。外部主体を閉路完成へ巻き込む場合は思考ではなく感情位相を含む。
- **Affected**: Meaning / README / Network
- **Disposition**: ACCEPTED
- **Decision**: 思考の自己内部閉鎖をGate 4中核条件として追加。外部対象は契機・照合対象・反例になりうるが、返答・同意・変化を閉鎖条件にしない。
- **Safeguard**: 自己内部閉鎖は自己完結的真理を意味せず、外部結果・原文抵抗・他者の返りで再開放されうる。

### RI-0004｜思考としての愛

- **Date**: 2026-08-08
- **Source**: User theoretical injection
- **Proposal**: 愛は、他者に触れながら相手を閉路完成へ巻き込まず、自己内部で返路を閉じる思考として読める。相手からの返りを必要とする場合は共感・愛情等の感情位相になる。
- **Affected**: Meaning / README / Boundary Ethics candidate
- **Disposition**: ACCEPTED
- **Acceptance Qualification**: LOCAL-SCOPE LIMIT
- **Decision**: 「思考としての愛」をMeaning文書の局所用法として追加。愛一般、愛着、共感一般、関係心理を所有しない。
- **Residual**: 思考としての愛と感情位相の愛情・共感が混合する場合の分離方法。
- **Recheck condition**: 独善、投影、一方的理想化を愛として自己閉鎖する反例が出た場合。

## 3. Intake Rule / 受付規則

返りを採用する際は、最低限次を確認する。

1. どの文書が概念所有者か。
2. 既存定義のどの不変項を変更するか。
3. どの主張位相に属するか。
4. 何を見えるようにし、何を落とすか。
5. 反例または失敗条件があるか。
6. 他文書へどの変更を伝播させるか。
7. 文書別Revision Historyと[`CHANGELOG.md`](./CHANGELOG.md)へ何を記録するか。

返りの採否は人気、感動、キャラクター権威、AIの流暢さによって決めない。
