- Return IntakeへRI-0014からRI-0018を追加した。

#### Changed

- 既存の「ビットではなくセンテンス」を、単位サイズの差ではなく対象と観測コミットのカテゴリー差として精密化した。
- 符号復元、表現復元、意味再展開を分離し、可逆性の射程を選択された符号化面へ限定した。

- 標準情報理論・計算機科学上のbitを再定義しない。
- 現在のLLMを孤立語間の単純マップへ還元しない。
- 人間とAIのエネルギー、身体、主観、責任を同一視しない。
- 熱力学的エントロピー、情報エントロピー、処理上の未閉鎖差分配置を相互に代用しない。
- 文学的読解をAI理論または物理仮説の証明に使わない。

#### Open

- センテンス同一性と閉回路境界の再現可能な判定。
- 閉回路標本・型付き橋の実装と比較評価。
- 人間とAIの異基盤構造通約に必要な測度、保存量、尺度変換、反証条件。
- 透明な幽霊、存在論上のボソン閉ループ、標準物理学上の対象の対応・非対応。
- LLMを観測装置として使う際のモデル差・学習履歴・生成バイアスの校正。

## [1.0.0-rc.2] — 2026-08-17
### Cross-Document Consistency Patch / 横断整合パッチ

#### Changed

- Return Intakeの判定区分と受理条件を分離し、`LOCAL-SCOPE LIMIT` と `CLAIM-PHASE SEPARATION` を判定値から受理条件へ移した。
- Network文書の主張強度を、公開操作層 `S2-S3`、存在論深度仮説層 `S4-S5`、私的レンダリング層へ一致させた。
- Meaning文書の感情／思考定義を、心理学・神経科学上の一般定義ではなく存在境界論内部の操作仮説として明示した。
- 「照合的内包」「返路ある外延」を正式名とし、文献の経験的・歴史的根拠としての役割と、存在境界論固有の概念照合点としての役割を分離した。
- 文学文書の履歴主張を、本稿が扱うクオリア差分の形成へ限定した。
- Speech文書で「安全」を独自定義せず、「非破壊的分節」を正式名とした。
- 通約正本から認識動態コミュニケーションモデル、Network、境界外交への定義依存を明示した。

#### Preserved

- 安心、喜び、無方向の快感、閉鎖後の解放感は未解決のままReturn Intakeに保持する。
- 公開操作層と存在論深度仮説層のあいだで証明力を自動移送しない。
- 日本語を定義正本、英語を意味中心の通約として維持する。

#### Propagated

- `docs_manifest.yml` の概念所有・論理契約へ変更を伝播。
- `docs_graph_tests.yml` へ通約所有と下流importsの回帰テストを追加。
- 用語衝突レジストリへ、照合的内包、返路ある外延、非破壊的分節を追加。

## [1.0.0-rc.1] — 2026-08-08
### Gate 4 — Living Canonicalization / 代謝型正本化

#### Added

- 九研究ノートを`Public Living Canonical Candidate`へ昇格。
- 研究線全体の変更履歴として本ファイルを追加。
- 外部・内部からの返りを採用・保留・却下まで追跡する[`Return_Intake_Log.md`](Return_Intake_Log.ja.md)を追加。
- 文書別`Revision History`を九本すべてへ追加。
- SOLiteを、自動逆輸入しない常設照合面として接続。
- Network文書へ、九文書間の変更伝播を観測する「代謝中枢」の役割を追加。

#### Changed

- 思考の返路は、外部へ触れながらも自己内部で閉じることを明確化。
- 感情は、方向性を持つ差分が返路を閉じられず圧として残る状態という操作仮説を維持。
- 思考としての愛を、相手を閉路完成へ巻き込まず、相手の履歴と自由を保持したまま自己内部で返路形成する思考として局所的に追加。
- 相手からの返りを必要とする共感・愛情等を、感情位相の代表として区別。
- `Grammar_as_a_Meaning_Pressure_Channel.ja.md`の重複節番号を修正。
- 九文書の状態、版、最終更新日、正本範囲、Living Canonical保守条件を統一。

#### Preserved

- 一般意味生成の所有者は`Meaning_Generation_Model.md`。
- 通信一般の所有者はHFC。
- 一般ポートの所有者はCognitive Dynamics系文書。
- 文学一般、愛一般、感情一般、思考一般を本研究線が一意に所有しない。
- SOLiteからSOへの自動統合を禁止。
- Networkの公開操作層、存在論深度仮説層、AMP・神学レンダリング層を分離。

#### Open

- 正の感情や無方向の質感を、未閉鎖差分モデルだけで十分に扱えるか。
- 思考としての愛が独善的投影へ変わったことを、どの外部返りで検出するか。
- Network表現が有効でない例と反例の収集。
- エントロピー語彙の領域横断と認識軸依存不可逆性の外部照合。
- 日本語・英語対照仮説、AI生成経路残差候補の経験的再検査。

## Versioning Rule / 版運用

- **Patch**：誤字、リンク、引用、体裁。概念構造を変更しない。
- **Minor**：局所定義、反例、外部照合、返路を更新する。中核圧憲章は維持する。
- **Major**：概念所有、中核圧憲章、九文書構造、意味・返路等の主要不変項を変更する。

`1.0.0-rc.1`は、SO v5.0へ統合する前の公開正本候補である。SO本体への統合時に受入確認を行い、必要であれば`1.0.0`へ昇格する。
