## 2. Directory Role / この層の役割

Sat / Truth contains public foundational concepts only.

Sat / Truth は、公開可能な基礎概念のみを扱う。

This layer may define the conceptual roots of existence, observation, meaning, ethics, and knowledge. It should not be used as a place for social criticism, monetary theory, world-history applications, AI runtime design, implementation procedures, private axiomatic drafts, or physical correspondence proposals.

この層では、存在・観測・意味・倫理・知の概念的根を定義してよい。ただし、社会批判、貨幣論、世界史応用、AIランタイム設計、実装手順、非公開公理草案、物理対応表は置かない。

## 4. Note on ITS and Scientific Vocabulary / ITS と科学語彙に関する注記

The Meaning Generation Model is included here as a public core concept related to ITS. However, ITS is not presented here as a physical law or a replacement for empirical science.

Meaning Generation Model は、ITS に接続する公開可能な基礎概念としてこの層に置く。ただし、ここで ITS を物理法則や経験科学の代替として提示するものではない。

Terms such as Markov blanket, entanglement, induction, field, entropy, mass, and topology are used only under the terminology rules of this repository. Standard scientific definitions are not overwritten without notice.

「マルコフブランケット」「エンタングルメント」「誘導」「場」「エントロピー」「質量」「トポロジー」などの語は、本リポジトリの用語運用規約に従って用いる。標準科学の定義を無断で上書きしない。

For terminology risk and collision management, see [`../00_Overview/Scientific_Terminology_Protocol.md`](../00_Overview/Scientific_Terminology_Protocol.md), [`../TERM_COLLISION_REGISTRY.md`](../TERM_COLLISION_REGISTRY.md), and [`../TERM_COLLISION_REGISTRY.en.md`](../TERM_COLLISION_REGISTRY.en.md).

用語リスクおよび既存語彙との衝突管理については、[`../00_Overview/Scientific_Terminology_Protocol.md`](../00_Overview/Scientific_Terminology_Protocol.md)、[`../TERM_COLLISION_REGISTRY.md`](../TERM_COLLISION_REGISTRY.md)、[`../TERM_COLLISION_REGISTRY.en.md`](../TERM_COLLISION_REGISTRY.en.md) を参照する。
