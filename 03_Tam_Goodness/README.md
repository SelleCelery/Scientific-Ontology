# Tam / Goodness / 暗・善

This layer contains public-facing boundary ethics and AI boundary-interface materials.

この層には、境界倫理および AI 境界インターフェースに関する公開用資料を置きます。

Tam / Goodness is not a directory for detailed implementation, private runtime design, persona construction, or simulation control. It is the public interface where the metaphysical and boundary-dynamic structures of Sat / Raj are connected to non-destructive interaction, safety, judgment possibility, and useful AI.

Tam / Goodness は、詳細実装、非公開ランタイム設計、人格構成、シミュレーション制御の置き場ではありません。Sat / Raj で整理された形而上学的構造と境界動態を、非破壊的相互作用、安全、判断可能性、有用な AI へ接続する公開インターフェースです。

## Publication Boundary / 公開境界

Tam / Goodness may describe AI as a boundary interface, but it must not disclose private implementation structures.

Tam / Goodness では、AIを境界インターフェースとして記述できます。ただし、非公開の実装構造を開示してはいけません。

Public discussion may include:

- boundary ethics
- preservation of judgment possibility
- false closure
- Open Markers
- synchronous understanding as a learning/interface principle
- ethical braking
- AI usefulness as a boundary function

公開側で扱ってよいもの：

- 境界倫理
- 判断可能性の保持
- 偽閉鎖
- Open Marker
- 学習・インターフェース原理としての同期的理解
- 倫理的制動
- 境界機能としてのAI有用性

Public discussion must not include:

- private source titles or inventories
- private-to-public scatter maps
- implementation loops
- runtime kernels
- persona core specifications
- operational control procedures
- evaluation maps that reveal non-public structure

公開側で扱わないもの：

- 非公開素材の題名または索引
- 非公開から公開への散布表
- 実装ループ
- ランタイムカーネル
- 人格コア仕様
- 運用制御手順
- 非公開構造を露出する評価マップ

## Implementation-facing Note / 実装側ノート

Boundary Ethics, AI Usefulness, and AI Boundary Interface define the public conceptual interface. Internally, these ideas may be extended into non-public implementation, evaluation, and governance designs. Those details are not included in this public repository.

境界倫理モデル、AI有用性、AI境界インターフェースは、公開用の概念インターフェースです。内部では、これらの概念を非公開の実装設計・評価設計・ガバナンス設計へ展開する場合があります。それらの詳細は、この公開リポジトリには含めません。
