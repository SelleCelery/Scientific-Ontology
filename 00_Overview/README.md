# Overview / 概要

This directory contains navigation and governance documents for the Scientific Ontology repository.

このディレクトリには、存在論科学リポジトリ全体を読むためのナビゲーション文書と運用規約を置きます。

## Documents / 文書

- `Scientific_Ontology_System_Map.md`  
  A high-level map of the relationship between Core, AMP, ITS/HFC, Sat/Raj/Tam, and Research Notes.  
  Core、AMP、ITS/HFC、Sat/Raj/Tam、Research Notes の関係を整理する高次マップ。

- `Scientific_Terminology_Protocol.md`  
  A terminology and publication-risk protocol for using scientific vocabulary without overwriting standard scientific definitions or exposing sensitive implementation details.  
  標準科学の定義を上書きせず、秘匿すべき実装詳細を露出させないための、科学語彙および公開リスク運用規約。
