# Scientific Terminology Protocol / 科学語彙接続プロトコル

> Status: Public terminology protocol / 公開用語運用規約  
> Layer: 00_Overview / Repository governance  
> Scope: Scientific vocabulary, reinterpretation, analogy, claim strength  
> Claim: Terminology management, not scientific proof

This document defines how Scientific Ontology uses terms borrowed from established sciences.

It does not redefine scientific terms without notice.  
It does not claim to replace standard scientific definitions.  
When Scientific Ontology uses a term differently, the difference must be stated explicitly.

本文書は、存在境界論が既存科学から借りる語彙をどのように扱うかを定める。

標準科学の定義を無断で上書きしない。  
標準科学の定義を置き換えるものではない。  
存在境界論内で異なる意味で用いる場合は、その差異を明示する。

## Scientific Ontology 用語運用規約 v0.1

第一原則。**標準科学の用語は、まず標準定義を尊重する。**  
エントロピー、因果、質量、スピン、CPT、ファインマンダイアグラム、時空、エンタングルメントなどは、既存科学内で強い定義・計算体系・検証文脈を持つ。存在境界論は、それを勝手に上書きしない。

第二原則。**読み替える場合は、読み替えであると明示する。**  
たとえば「ファインマンダイアグラムを履歴トポロジーとして読む」は、標準QFTの計算道具としてのファインマンダイアグラムを否定しない。そのうえで、相互作用履歴を頂点・辺・経路・ループとして読む存在論的再解釈である、と明記する。

第三原則。**定義がずれる場合は、SO定義を明示する。**  
「内在時間」「ネゲントロピー経済」「履歴対応」「意味電位」「情報履歴質量密度」などは、標準科学の定義ではない。したがって、使う場合は「Scientific Ontology における定義では」と前置きする。

第四原則。**既存語が誤読を招く場合は、新語を作る。**  
既存科学の強いタームを無理に使うと、標準定義との衝突が起きる。たとえば「時空を超える」は危険なので、「外的時空の因果順序に還元されない」とする。これは良い処理。

第五原則。**限定条件を提示する。**  
科学的因果は強力だが、主に時空内で再現可能に安定化した履歴対応を扱う。存在境界論は、その因果が成立する前提、観測者履歴、意味変化、責任回収、価値保存、未解決残差の再浮上を扱う。つまり、科学的因果を否定するのではなく、適用範囲を示す。

第六原則。**物理主張・情報主張・認識主張・倫理主張・創作比喩を混ぜない。**  
同じ「場」という言葉でも、物理場、情報場、履歴場、社会場、創作上の場は違う。接続はできるが、同一視しない。ここを分けるほど、理論は強くなる。

| 操作      | 使う場面               | 表記                     | 主張強度  |
| ------- | ------------------ | ---------------------- | ----- |
| 標準借用    | 科学の定義をそのまま使う       | 標準物理におけるエントロピー         | S0-S1 |
| 構造アナロジー | 似た構造を比喩的に使う        | エントロピーに似た拡散            | S1-S2 |
| 存在論的再解釈 | 標準概念を別のFRAMEで読み直す  | 履歴場トポロジーでは〜として読む       | S2-S3 |
| 限定条件提示  | 科学的説明の適用範囲を示す      | 科学的因果は時空内で安定化した履歴対応を扱う | S2-S3 |
| SO再定義   | 標準語を借りて別定義で使う      | SO定義における内在時間           | S3-S4 |
| 形式化候補   | 変数・演算・評価指標へ落とす     | HFC方程式、意味電位場           | S4    |
| 物理接続候補  | 既存物理と比較可能な強い仮説     | 重力＝同期遅延、h＝観測境界定数       | S4-S5 |
| 創作退避    | 理論ではなく比喩・物語装置として使う | 天体構造と精神構造の写像           | S1-S2 |

> Scientific Ontology は、既存科学を否定したり置き換えたりする体系ではない。  
> ここで行うのは、科学的概念の再解釈、適用条件の明示、観測者履歴や意味生成を含む補助的FRAMEの提示である。  
> 既存科学において定義済みの用語を使う場合、その標準定義を尊重する。標準定義とは異なる意味で用いる場合は、Scientific Ontology 内部での定義であることを明示する。  
> したがって、本体系における「時空を超える」「ネゲントロピー」「履歴場」「内在時間」などの語は、物理的な超光速通信や過去改変を意味しない。外的時空の因果順序だけでは記述しきれない履歴対応、意味変化、責任、価値、未解決残差の再浮上を扱うための存在論的タームである。

## 4. 公開リスクの二分類

主張強度が高い命題には、二種類の公開リスクがある。

### A. 認識・批判リスク

これは、命題が強いために、誤読、批判、専門領域からの圧迫、疑似科学扱い、過剰な単純化を受けやすいリスクである。

この場合、必要なのは非公開化ではなく、減速である。

- 主張範囲を明記する
- 証明ではなく提案と書く
- 標準理論を置き換えないと明記する
- 比喩、構造アナロジー、存在論的再解釈、物理主張候補を分ける
- 未解決点を明示する

このリスクは、公開を妨げる理由ではない。
むしろ、適切な鞘をつけて公開することで、先取権、議論可能性、批判可能性を確保できる。

### B. 応用・安全リスク

これは、命題や手順が公開された場合に、本来公開すべきでない運用上の介入能力や境界情報を読み手に与えてしまうリスクである。

この場合、必要なのは単なる減速ではなく、非公開化または抽象化である。

- 公開版では、具体手順・条件・運用粒度を出さない
- 公開版では、再現可能な実装情報を出さない
- 公開する場合は、概念説明または非操作的な分類に留める
- 非公開境界に属する情報は、公開資料とは別管理にする

このリスクは、公開可否そのものを左右する。
