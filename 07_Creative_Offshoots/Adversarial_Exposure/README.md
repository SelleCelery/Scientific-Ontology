## 1. Directory Role / ディレクトリの位置づけ

ここでは、01の『正しさ・個性・無・切断』を、Business、対人関係での退避、身体を越えて残る判断の履歴へ接触させる。論考は元型を説明するだけでなく、相手をモデル化する自分自身へも反論を返す。付録は、その接触で何が対応し、何が元型だけでは閉じなかったかを残す。

`Adversarial`は、人や文化を敵として分類するための語ではない。こちらの説明を採用しない条件や、こちらの説明を壊し得る問いにさらす、というこのディレクトリの働きを指す。掲載事例は構造的な相互照合であり、独立した外部者による反証試験を完了したという宣言ではない。
