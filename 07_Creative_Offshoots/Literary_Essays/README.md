## 1. Directory Role / ディレクトリの位置づけ

ここでは、存在境界論を順番に習得する前に、一続きの文章として読める形へ持ち出す。生活や他者との接触から入り、必要になったところで正本・研究・応用へ戻る。読みやすいことだけを成功条件にせず、説明を変えたときに何が通じ、何が抜け落ちるかも受け取る。

『問いを閉じず、境界を踏まないために』は、方法、正しさ、帳簿、平和を四つの入口として扱う。正しさの章からは01の定義ownerへ戻れる。読者がその語彙をすべて採用することは前提にしない。

## 2. Public Scope / 公開範囲

日本語本文を言語上の正本とし、既存の全文英語通約を別ファイルで保持する。平易化は主張の保証を増やさず、比喩は標準科学・会計・法・政治の定義権限を代行しない。読み物は、それらとの不一致を隠すための面でもない。

ここでの「正しい」の説明は態度と読書導線を示すもので、判定条件の全体ではない。「次にもできる状態」を問う帳簿も完成済みの会計基準ではなく、平和についての叙述も無制限の報復を正当化しない。本文に置かれたこれらの境界を、要約や通約によって落とさない。
