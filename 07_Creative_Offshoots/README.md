## 1. Layer Role / 層の位置づけ

境界は、隔てる線だけではなく、通路であり、異なるものが接触する緩衝地帯でもある。07は、存在境界論の元型、とくに`01`–`03`に置かれた構造・認識・規約を、**SOの共有文法を前提にしない異質な条件へ曝露する場所**である。

ここで主眼になるのは、理論を分かりやすく言い換えることではない。異なる生活上の問い、価値体系、学問語彙、文化、物語、世界観、批判、表現形式へ持ち出したとき、元型がどこで通じ、どこで崩れ、どこでそもそも接続できないのかを見ることである。創作やエッセイは、その接触を起こす手段の一つであって、07を創作専用棚にするものではない。

`05_Research_Notes`との違いは、批判の強さではなく**共有文法の有無**にある。05はSOの語彙や構造をいったん共有した内在的批判・拡張である。07は、その共有を仮定せず、外部・異質系から元型を壊しに来る経路を開く。そのため、返ってきた反応を少なくとも次のように分けて保持する。

- 理解不能・読解不能
- 通約または翻訳の失敗
- 前提・公理・価値体系の衝突
- 理解したうえでの反論
- 反例・反証候補
- 適用限界
- 単純な不同意や価値判断の衝突

この分類は自動判定ではない。区別できない反応は未分類のまま残す。理解されなかったことを理論の勝利にも敗北にもせず、反論されたことを読者の理解不足へ回収しない。

| 領域 | この案内で区別する主な働き |
|---|---|
| 01–03 | 境界を読む元型と生成核。構造を規定し、認識・通信・意味・規約の条件を扱う。 |
| 05 | 元型を共有文法の内側から批判し、拡張する研究面。 |
| 04 | 01–03と、必要に応じて05を踏まえ、心理・経済・政治・AI・制度・アプリケーションなどへスピンアウトする応用面。 |
| 06 | 01–05を別の知覚・表現形式へ写し、保持されたものと失われたものを調べるレンダリング研究。 |
| 07 | 共有文法を前提にせず元型を異質な条件へ曝露し、通約失敗・反論・反証候補・残差を受け取る外部接触面。 |

これは成熟度や優劣の順ではなく、主な働きの違いである。同じ文書が複数の働きを持つこともある。v5.1では既存文書の大規模移動を行わず、この境界説明と実例を先に置く。配置の全面監査は後続の独立工程とする。

07で生じた研究線が独自の語彙・方法・対象領域を持ち、SO内部の外部曝露面ではなく自立した系として安定する場合、将来別の領域へスピンアウトする可能性は残す。ただし、08というフォルダや体系を今ここでは作らない。

## 2. Public Scope and Claim Profile / 公開範囲と主張強度

07への配置は、主張を弱いものへ格下げする操作でも、論証上の責任を免除する操作でもない。読み物には読み物としての強い主張があり得る。形式、主張の強さ、検証段階、公開可能性は分けて読む。

英語通約は別ファイルに置き、意味の不一致は日本語正本へ戻って照合する。「日本語正本」はその文書の言語上の基準を意味し、SOの全概念についての定義ownerであることを意味しない。

掲載している監査付録は、異質な対象に対する構造照合と残差の記録である。独立した外部研究者の査読や十分な実証探索が完了したという記録ではない。付録自身が残している「未判定」「探索未飽和」を、読みやすさや数式の整った外観によって「確認済み」へ変えない。

## 3. Included / Not Included / 含むもの・含まないもの

含むのは、読み物、表現を介した通約、異質な対象への曝露、反論や自己批判、およびそこから戻る残差の記録である。07を創作だけの置場、未完成文書の退避先、SOへの賛同文の集積場所にはしない。

01の正本全文を複製した別の正本は置かない。今回の監査は、[正しさ・個性・無・切断の正本](../01_Sat_Truth/正しさ・個性・無・切断_論理通信トポロジー.ja.md)を参照して行う。監査付録の要約・候補式・残差は、その正本を書き換えない。原資料を合本にした作業用ファイルも、別の定義ownerとして登録しない。

非公開資料の実bytes、個人の非公開履歴、一回限りの実行packや生runは、07へ移すことで公開可能になるものではない。出典の保持と全文の再配布は別に判断する。

## 5. Maintenance Notes / 運用メモ

接触から返るものは、その内容に応じて別の返路へ送る。

- 元型の定義不足・形式化不足として継続研究すべきもの → `05_Research_Notes`
- 応用先での設計・実践条件として処理すべきもの → `04_Applications`
- 表現圧縮や可視化による損失 → `06_Visual_Materials`またはsource本文
- 既存定義を直接再照合すべきもの → 該当するcanonical owner

07の成果を正本へ無標識に昇格させない。物語や比喩が働くこと、形式化できること、読者に理解されること、理論が真であることを同一視しない。

外部通約は普及だけのために行うものではない。異なる文法・経験・価値体系から、内部では生成しにくいdefeater、反論、摩擦、残差を受け取るためのIngressでもある。ただし、外部から来たという理由だけでその内容を優先しない。返ってきた差分が何を壊したのかを追跡し、必要なら05またはdefinition ownerで再構成する。

今回の数式本文はインライン数式と独立行のブロック数式を用いる。コードとして示した文字列と数式は分離する。通約時には式の関係を保持し、表記上の疑問は本文の定義変更で黙って解消せず、該当ディレクトリの案内に残す。
