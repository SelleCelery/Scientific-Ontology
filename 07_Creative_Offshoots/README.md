## 1. Layer Role / 層の位置づけ

境界は、隔てる線だけではなく、通路であり、異なるものが接触する緩衝地帯でもある。07は、存在境界論の元型、とくに01–03に置かれた構造・認識・規約を、異なる生活上の問い、語彙、価値体系、表現形式へ持ち出してみる場所である。分かりやすく説明するだけでなく、元の記述の中では現れにくかった反論、理解の失敗、適用限界、残差が返ってくる経路を開く。

ここでは、理論を知らなくても、読み物から入ってよい。読んで納得することも、引っかかることも、読むのをやめることもある。その反応をすべて理論の正しさへ回収しない。理解されなかったことと、理解したうえで反論されたことを区別する一方、区別できない反応は未分類のまま残す。存在境界論への同意や専門語の習得を、異議を持ち込む資格にしない。

| 領域 | この案内で区別する主な働き |
|---|---|
| 01–03 | 境界を読む元型と生成核。構造を規定し、認識・通信・意味・規約の条件を扱う。 |
| 05 | その元型に対する批判と拡張を研究として進める。 |
| 04 | 01–03と、必要に応じて05を踏まえ、心理・経済・政治・AI・制度・アプリケーションなどへスピンアウトする。 |
| 06 | 01–05を異なる知覚・表現形式へ写すレンダリング研究。何が保持され、何が失われるかも対象にする。 |
| 07 | 元型を異質な条件へさらし、通約・反論・再照合のための接触面を作る。 |

これは成熟度や優劣の順ではなく、主な働きの違いである。同じ文書が複数の働きを持つこともある。v5.1では既存文書の大規模移動を行わず、この境界説明と実例を先に置く。配置の全面監査は後続の独立工程とする。07から自立した成果が将来別の領域へスピンアウトする可能性は残すが、08というフォルダや体系を今ここでは作らない。

## 2. Public Scope and Claim Profile / 公開範囲と主張強度

07への配置は、主張を弱いものへ格下げする操作でも、論証上の責任を免除する操作でもない。読み物には読み物としての強い主張があり得る。形式、主張の強さ、検証段階、公開可能性は分けて読む。

英語通約は別ファイルに置き、意味の不一致は日本語正本へ戻って照合する。「日本語正本」はその文書の言語上の基準を意味し、SOの全概念についての定義ownerであることを意味しない。

掲載している監査付録は、異質な対象に対する構造照合と残差の記録である。独立した外部研究者の査読や十分な実証探索が完了したという記録ではない。付録自身が残している「未判定」「探索未飽和」を、読みやすさや数式の整った外観によって「確認済み」へ変えない。

## 3. Included / Not Included / 含むもの・含まないもの

含むのは、読み物、表現を介した通約、異質な対象への曝露、反論や自己批判、およびそこから戻る残差の記録である。07を創作だけの置場、未完成文書の退避先、SOへの賛同文の集積場所にはしない。

01の正本全文を複製した別の正本は置かない。今回の監査は、[正しさ・個性・無・切断の正本](../01_Sat_Truth/正しさ・個性・無・切断_論理通信トポロジー.ja.md)を参照して行う。監査付録の要約・候補式・残差は、その正本を書き換えない。原資料を合本にした作業用ファイルも、別の定義ownerとして登録しない。

非公開資料の実bytes、個人の非公開履歴、一回限りの実行packや生runは、07へ移すことで公開可能になるものではない。出典の保持と全文の再配布は別に判断する。

## 5. Maintenance Notes / 運用メモ

接触から返るものは、理解不能、通約の失敗、異なる前提からの反論、反証候補、適用限界、価値判断の衝突などに分けて保持する。この列挙は網羅的な分類でも、自動判定手続でもない。理解できないという反応だけで元型を反証済みにはしないが、理解できない側の欠陥として片づけもしない。

残差は、05の研究へ、04の設計・実践へ、または既存の定義ownerへの再照合へ返す。返送先は残差の内容によって選び、07の成果を正本へ無標識に昇格させない。物語や比喩が働くこと、形式化できること、理論が真であることも同一視しない。

今回の数式本文はインライン数式と独立行のブロック数式を用いる。コードとして示した文字列と数式は分離する。通約時には式の関係を保持し、表記上の疑問は本文の定義変更で黙って解消せず、該当ディレクトリの案内に残す。
